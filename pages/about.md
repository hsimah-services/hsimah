Hey, I'm Hamish. I'm a software engineer at Meta, and an Australian expat living in the Pacific Northwest.

## What's this blog?

A place to put stuff that doesn't belong on my [technical blog](https://hbla.ke). Expect infrequent posts about whatever I'm into at the time. Could be anything.

## A bit about me

When I'm not writing code I'm usually outside. The PNW is hard to beat for bike riding, especially with my dogs. I'm also into good coffee, tinkering with side projects, and occasionally convincing myself I'll post here more often than I actually will.

That's about it. Thanks for stopping by.

## This Site

Built with [markr](https://github.com/hsimah-services/markr) — a minimal static blog engine I wrote. Posts are markdown files prerendered to static HTML at build time. The only dependency is `marked` for markdown parsing, and that runs at build time. No runtime JavaScript required.
